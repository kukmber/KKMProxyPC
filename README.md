## Что это такое

KKMProxy — оболочка над тремя проверенными программами. Она сама скачивает их,
пишет им настройки, запускает, следит за состоянием и показывает журнал.
Сами способы обхода работают по-разному, и это хорошо: если не помогает один,
включается другой.

| Способ | Что делает | Когда пригодится | Права администратора |
|---|---|---|---|
| **VPN** ([mihomo](https://github.com/MetaCubeX/mihomo)) | Весь трафик идёт через ваш сервер по подписке | Когда нужен доступ куда угодно и свой сервер есть | Только для режима TUN |
| **TgWsProxy** ([tg-ws-proxy-rs](https://github.com/valnesfjord/tg-ws-proxy-rs)) | Telegram ходит через WebSocket | Telegram не грузит фото и не отправляет сообщения | Нет |
| **Zapret** ([набор Flowseal](https://github.com/Flowseal/zapret-discord-youtube) на ядре [bol-van/zapret](https://github.com/bol-van/zapret)) | Меняет пакеты так, что фильтр провайдера не узнаёт запрос | Discord, YouTube и другие сайты — без VPN, на полной скорости | Да |

Всё три можно включать по отдельности или вместе.

## Установка

Готового установщика пока нет — программа собирается из исходников,
см. [Сборка из исходников](#сборка-из-исходников).

**Ядра скачивать вручную не нужно.** При первом включении раздела программа
сама возьмёт нужную версию из релизов на GitHub и положит её в свою папку.

## Пульт

Первая вкладка — три переключателя и кнопка «Перезапустить».

<img src="docs/images/control.png" width="760" alt="Пульт">

- **Переключатель** включает и выключает способ. Под ним идёт время работы.
- **Перезапустить** поднимает заново только то, что сейчас включено. Помогает,
  когда соединение «залипло» после смены сети, Wi-Fi или выхода из спящего режима.
- Если что-то не включилось, наведите указатель на плитку — во всплывающей
  подсказке будет причина.

Точка на значке слева в узкой панели показывает, что раздел работает,
даже когда вы смотрите другую вкладку.

## VPN

Ядро — [mihomo](https://github.com/MetaCubeX/mihomo), то же, что во FlClashX.
Понимает Clash/Mihomo YAML, Reality, Hysteria2, xhttp и другие протоколы.

<img src="docs/images/vpn.png" width="760" alt="VPN">

### Добавить подписку

Нажмите **«Добавить подписку»** и выберите удобный способ:

1. **Ссылка.** Вставьте адрес подписки — если она уже скопирована, программа
   подставит её сама при открытии окна.
2. **Из буфера.** Годится и для одной ссылки, и для списка серверов, и для
   целого конфига.
3. **Из файла.** Подойдут `.yaml`, `.yml`, `.txt`, `.conf`.

Понимаются форматы: Clash/Mihomo YAML, base64 и ссылки `vless://`,
`hysteria2://`, `trojan://`, `ss://`, `vmess://`.

> **Совет.** Для YAML-подписки конфиг берётся целиком — работают её правила и
> списки. Программа меняет в нём только своё: порты, DNS и режим.

Под названием подписки видно, сколько в ней серверов, когда она обновлялась,
сколько трафика осталось и до какого числа она действует — если сервер
присылает эти данные.

Кнопка со стрелками обновляет подписку. В меню «⋯» — переименовать,
скопировать ссылку, удалить.

### Режимы

**Маршрут** — что отправлять через VPN:

- **Правила** — решают правила из подписки: зарубежное через VPN, российское напрямую.
- **Всё** — весь трафик через VPN.
- **Напрямую** — VPN не используется, но ядро остаётся запущенным.

**Способ** — как перехватывается трафик:

- **Системный прокси** — программа прописывает себя в настройках Windows.
  Прав администратора не нужно, но некоторые программы прокси не замечают
  (часто игры и отдельные мессенджеры).
- **TUN** — виртуальный сетевой адаптер, через него идёт трафик всей системы,
  включая такие программы. **Нужны права администратора**: кнопка «Перезапустить
  от администратора» появится прямо на странице.

### Выбор сервера

Список справа появляется после подключения.

- Флаг определяется по названию сервера, рядом — протокол и задержка в мс.
- **Поиск** и фильтр по протоколу — над списком.
- Значок молнии проверяет задержку всех серверов, клик по числу — одного.
- Если сервер не ответил три раза подряд, он помечается значком; программа
  сама перепроверяет такие серверы каждые 30 секунд и снимает отметку при
  первом успехе.
- Выбранный сервер отмечен полосой слева. При переключении старые соединения
  закрываются, чтобы они не остались на прежнем сервере.

Скорость, трафик за сессию, время и число соединений показываются под
индикатором слева.

## Прокси для Telegram

Локальный MTProto-прокси, который разговаривает с серверами Telegram через
WebSocket. Помогает, когда обычные подключения Telegram режут.

<img src="docs/images/telegram.png" width="760" alt="Прокси для Telegram">

1. Нажмите **«Запустить»**.
2. Нажмите **«Применить в Telegram»** — откроется Telegram с готовыми
   настройками, останется подтвердить. Или скопируйте ссылку кнопкой рядом.

Что полезно знать:

- **Секрет постоянный.** Ссылка не меняется от запуска к запуску, поэтому
  применять её в Telegram нужно один раз.
- **Прокси слушает только этот компьютер** (127.0.0.1). Другим устройствам в
  сети эта ссылка не подойдёт — так безопаснее.
- **Порт.** По умолчанию 1443. Если он занят другой программой, берётся
  свободный, а под полем появится строка с настоящим номером — ссылка выше
  уже будет с ним.
- **Число подключений** считает Windows: само ядро такой статистики не отдаёт.
- Список запасных доменов Cloudflare включён сразу — это второй путь до
  Telegram, когда основные адреса недоступны.

## Zapret — обход блокировок

Discord, YouTube и другие сайты без VPN. Трафик остаётся прямым и идёт на полной
скорости — меняется только то, по чему фильтр провайдера узнаёт запрос.

<img src="docs/images/zapret.png" width="760" alt="Zapret">

**Нужны права администратора**: обход работает через драйвер WinDivert.
Если их нет, на странице будет кнопка перезапуска.

### Стратегии

Берутся из набора [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube):
два десятка готовых вариантов (`general`, `general (ALT)`, `general (ALT2)` и так
далее), обкатанных на российских провайдерах. Программа читает их прямо из
файлов набора, поэтому после обновления ядра список пополняется сам.

Провайдеры фильтруют по-разному, поэтому нормально, что подходит не первая
стратегия. **Подобрать автоматически** прогоняет их по очереди и показывает,
сколько сайтов открылось на каждой, вместе с замером без обхода — чтобы было
видно, помогает ли обход вообще.

Можно вписать и свою строку аргументов winws: перед сохранением она проверяется
самим ядром.

> Тот же приём помогает и Telegram: если TgWsProxy не нужен, попробуйте
> сначала включить один Zapret.

## Настройки и обновление ядер

<img src="docs/images/settings.png" width="760" alt="Настройки">

У каждого ядра своя строка: установленная версия, последняя вышедшая и ссылка
на релизы.

- **Скачать / Обновить** — кнопка на каждое ядро по отдельности.
- **Обновить всё** — появляется, когда обновлений несколько.
- **Проверить** — сверяет версии с GitHub прямо сейчас.
- Раз в сутки версии проверяются сами: у значка настроек появится точка.
  Устанавливает обновление только кнопка — так новая версия ядра не изменит
  поведение внезапно.
- Работающее ядро при обновлении останавливается и запускается снова само.
- Скачанная версия важнее той, что пришла с установщиком, поэтому обновлять
  можно без прав администратора.

## Окно и значок в трее

- **Крестик прячет окно в трей**, программа продолжает работать. Выход — через
  меню значка.
- В меню значка есть быстрое включение и выключение VPN.
- Вторая копия программы не запускается: повторный запуск просто показывает
  уже открытое окно.
- Окно следует за темой Windows — светлой или тёмной, и использует эффект Mica
  на Windows 11.
- Ядра привязаны к процессу программы: если её закрыть или снять из диспетчера
  задач, Windows остановит и их. Системный прокси возвращается на место даже
  после аварийного завершения.

## Если что-то не работает

**«Нужны права администратора»**
Режим TUN и Zapret работают через драйверы. Нажмите «Перезапустить от
администратора» — программа перезапустится сама и продолжит с того же места.

**«winws.exe уже запущен другой программой»**
Значит, обход DPI у вас уже включён чем-то ещё (например, GoodbyeDPI, Zapret
или сборкой вроде slipgate). **Два обхода одновременно рвут сеть целиком** —
они перехватывают одни и те же пакеты. Закройте ту программу и попробуйте снова.
KKMProxy проверяет это до запуска и не даст сломать соединение.

**Пропал интернет**
Выключите всё на Пульте. Если не помогло — закройте программу: системный прокси
вернётся на место, а ядра остановятся вместе с ней.

**VPN не подключается**
Смотрите Журнал, вкладку «Ядро VPN». Частые причины: подписка устарела —
обновите её кнопкой; сервер не отвечает — выберите другой в списке справа.

**Telegram не видит прокси**
Проверьте, что номер порта в ссылке совпадает с тем, что показан на странице:
если порт 1443 занят, программа берёт другой и пишет об этом.

**Программу ругает SmartScreen**
Установщик пока не подписан сертификатом. Нажмите «Подробнее» → «Выполнить в
любом случае».

## Где лежат файлы

Настройки, подписки и скачанные ядра:

```
%LOCALAPPDATA%\io.github.kukmber.kkmproxypc
```

| Папка или файл | Что внутри |
|---|---|
| `settings.json` | настройки программы |
| `profiles.json` | список подписок |
| `profiles\` | сами конфиги подписок |
| `cores\mihomo`, `cores\tgws`, `cores\zapret` | скачанные ядра и их версии |
| `mihomo\` | рабочая папка VPN: конфиг, правила, geo-базы |

Чтобы начать с чистого листа, закройте программу и удалите эту папку.

## Сборка из исходников

Нужны [Node.js](https://nodejs.org/), [Rust](https://rustup.rs/) и
Visual Studio Build Tools с компонентом C++.

```bash
git clone https://github.com/kukmber/KKMProxyPC.git
cd KKMProxyPC
npm install
npm run tauri dev      # запуск с автоперезагрузкой
npm run tauri build    # установщик NSIS в src-tauri/target/release/bundle
```

Проверки:

```bash
cd src-tauri && cargo test    # разбор подписок, сборка конфига, стратегии
npx tsc --noEmit -p .         # типы интерфейса
```

## Как всё устроено внутри

Tauri 2 (Rust) + React и Fluent UI. Интерфейс — обычная веб-страница в окне
Windows, вся работа с процессами, правами и сетью — на Rust.

| Файл | Что делает |
|---|---|
| `src-tauri/src/vpn.rs` | запуск mihomo, проверка готовности, системный прокси |
| `src-tauri/src/config.rs` | итоговый конфиг: порты, контроллер, DNS, TUN, правила |
| `src-tauri/src/subscription.rs` | разбор подписок и ссылок |
| `src-tauri/src/tgproxy.rs` | прокси для Telegram и ссылка `tg://proxy` |
| `src-tauri/src/zapret.rs` | обход DPI, стратегии, проверка параметров |
| `src-tauri/src/cores.rs` | версии ядер, проверка и обновление с GitHub |
| `src-tauri/src/child.rs` | общий запуск ядер: Job Object, журнал, падения |
| `src-tauri/src/winsys.rs` | права администратора, поиск процессов, версия Windows |
| `src/pages`, `src/components` | страницы и элементы интерфейса |

Решения, которые стоили отладки и потому закреплены в коде:

- Файлы правил и geo-базы скачиваются заранее и напрямую: пока mihomo тянет их
  сам, он не пропускает трафик. Что не скачалось — временно исключается из
  конфига вместе с правилами, которые на это ссылаются, и догружается уже через
  VPN с перечитыванием конфига без переподключения.
- Готовность ядра проверяется запросом к его же контроллеру через его SOCKS-порт
  (первым правилом идёт `IP-CIDR,127.0.0.1/32,DIRECT,no-resolve`). Так проверка
  не зависит от того, отвечает ли сервер VPN.
- DNS: `respect-rules: true` и российский резолвер в `proxy-server-nameserver` —
  иначе не разрешается адрес самого сервера, а зарубежный DoH недоступен.
- Порт контроллера и секрет — случайные при каждом запуске.
- Сервер с испорченным ключом Reality пропускается при разборе ссылок: иначе
  из-за одного такого сервера не запускается всё ядро.
